Embed harness — pre-merge snapshot

Renders the built embed against dev-legacy.json: a snapshot in the shape published before categories became tags. It carries categories and a category per place, and its tagGroups have no colours — exactly what is sitting on customers’ sites right now. Nothing produces this shape any more, and §7 says a published file is read forever, so this page is the only thing standing between that promise and a silent regression.

Run npm run build:embed, start the dev server, then open /embed/dev-legacy.html. It must look the way it always did:

Pins keep their category colours. The shops are orange and the depots blue, and a place with neither a category nor a custom pin is the neutral grey. If every pin is grey, the fallback in colorOf (embed/src/map.ts) has been dropped and every already published map has lost its colours.

Cards still draw the chip. The card’s tag row shows this location’s tags, and the retired Category block — on any layout still naming it — draws the category with its own dot.

The list rows still carry a coloured chip, and search still finds a location by its category’s label — type depots and the map should narrow to those two.

The tag filters still work even with no colours on the tags: two groups, OR within one and AND across them.
