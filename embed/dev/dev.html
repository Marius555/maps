Embed harness

Renders the built embed against dev.json, a fixture snapshot — no Appwrite, no login, no publish. Source lives in embed/dev/ and is copied into the build output by Vite’s publicDir, so it never reaches a production deploy.

Run npm run build:embed, start the dev server, then open /embed/dev.html.

Checklist: pins coloured by category (uncategorised ones grey), the pair beside the flagship clusters at low zoom, clicking a pin opens a popup, the category chips filter and refit, search narrows by name or address, a no-match search says so, and OpenStreetMap attribution shows exactly once. Set allowedDomains to something other than localhost and the map should refuse to render, warning to the console only.
