How to check analytics
  1. Open your browser's developer tools, go to Network, and filter by collect.
  2. Search, open a card, press Directions — no request should appear while you do.
  3. Switch to another tab. Exactly one POST /api/collect fires and answers 204.
  4. Reload the map's Analytics tab — the visit is there.

Visitor analytics has to be on and the map redeployed first: the address visits are sent to is written in at publish time. A 204 is also the answer when a visit is dropped (analytics switched off since, a site that isn't allowed, the monthly limit reached), so check the server log rather than the status code. Visits recorded here are real rows — delete them afterwards if you need to.
